## Single purpose

Send one user-entered question to the AI websites the user selects, using the user's existing signed-in browser sessions, and report whether each send succeeded.

> Ask ChatGPT, Claude, Gemini, Perplexity, Grok and Manus at once using your existing accounts.

Detailed description:

> Ask once instead of copying the same question into multiple AI tools.
>
> Choose ChatGPT, Claude, Gemini, Perplexity, Grok, or Manus. Chorus opens or safely reuses each website, sends your question through your existing signed-in session, and shows which platforms succeeded or need attention.
>
> Chorus preserves existing drafts and conversations, restores progress when the popup closes, and lets you retry only failed platforms.
>
> Privacy: Chorus has no server. Your prompt is sent only to the AI websites you choose. Chorus does not collect prompts, AI responses, browsing history, account credentials, or analytics.

## Permission justifications

| Permission | Why it is required | Scope control |
| --- | --- | --- |
| `storage` | Remembers language and selected platforms locally; keeps the current task recoverable in browser-session storage | No sync or remote analytics |
| `scripting` | Re-injects the packaged content script into already-open supported tabs after an extension install or update | Can run only on declared supported hosts |
| `tabGroups` | Groups two or more newly created AI tabs so the user can identify the batch | Does not read unrelated tab content |
| Host access | Finds prompt inputs, sends the user-entered question, and confirms the send on six supported services | Ten exact HTTPS host patterns; no `<all_urls>` |

The broad `tabs` permission is intentionally not requested; the declared host permissions provide the supported-tab URL access needed by the launch feature.
