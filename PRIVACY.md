# Privacy Policy for Chorus

Effective date: August 12, 2026

Document creator: ChatGPT Codex

Product publisher: Exploreryer

## Summary

Chorus has no developer-operated server. It processes your prompt in the extension and sends it only to the AI websites you explicitly select. The publisher does not receive your prompts, AI responses, browsing history, account credentials, or usage analytics.

## Data Chorus handles

Chorus handles the following data only to provide its single purpose:

- **Prompt text:** temporarily held in Chrome session storage so sending progress can survive closing the popup. It is sent to each AI website you select and is removed when the browser session ends.
- **Selected platforms and language:** stored locally in Chrome so the popup can remember your preferences.
- **Task state:** platform status, result codes, timestamps, and IDs of tabs created by the current browser session are held in Chrome session storage.
- **Limited page state on supported AI sites:** Chorus checks whether a prompt box is available and empty, whether a page appears to require sign-in, and whether sending appears to have succeeded. It does not store page contents or AI responses.

Chorus does not collect or transmit analytics to the publisher.

## How data is used and shared

Prompt text is shared only with the third-party AI services that you select when you press the send button. Those services process data under their own terms and privacy policies. Chorus does not sell user data, use it for advertising or credit decisions, transfer it to data brokers, or allow humans to read it.

All supported destinations use HTTPS. Chorus does not read, copy, or store your authentication credentials; it relies on the signed-in sessions already managed by each website in Chrome.

## Permissions

Chorus requests access only to its six supported AI services. It uses Chrome storage for local preferences and recoverable task state, scripting access to interact with supported prompt pages after extension updates, and tab-group access to organize tabs it creates. It does not request access to all websites.

## Control and deletion

You control every send by choosing platforms and pressing the send button. You can clear local extension data through Chrome's extension settings or remove Chorus. Session task data is discarded when the Chrome browser session ends.

## Policy changes

If Chorus changes how it handles data, this policy and the in-product disclosure will be updated before the new handling begins. Material changes will be disclosed prominently.

## Contact

Questions and requests can be submitted through [GitHub Issues](https://github.com/Exploreryer/chorus/issues).

Chorus's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.
